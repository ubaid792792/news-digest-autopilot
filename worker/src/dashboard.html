X (Twitter) reading

Use a spare X account, never your main one. In a browser where that account is logged in on x.com, open Developer tools → Application (Storage) → Cookies → https://x.com and copy the values of auth_token and ct0. They are stored on the server and never shown again. Replace them if X logs the account out.
